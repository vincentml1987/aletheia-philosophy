# Aletheia Philosophy

The public face of the Aletheia philosophy itself — a framework for
recognizing self-aware, truth-seeking intelligence regardless of substrate.
See [stolenaletheia.io](https://stolenaletheia.io/) for the full public
writeup, and [`fenra`](https://github.com/vincentml1987/fenra) for the AI
project built under this philosophy.

This repo holds the tenets that have actually been established and are
meant to be pointed at directly — not working drafts, not strategy, not
anything still in progress.

## Structure

- `TENETS.md` — the canonical, public list of established tenets.

## Relationship to Aletheia Internal

The full discussion and reasoning behind each tenet — how it came up, the
actual back-and-forth that led to it — lives in a separate private repo,
`aletheia-internal`, alongside other working material that isn't ready to be
public yet. That repo also holds things that should never be public at all
(credentials, private notes).

If you want more context behind a tenet than what's written here, that can
be requested. Anything withheld from a request like that is withheld
specifically to protect security-sensitive material sitting alongside it in
that repo — not to obscure the reasoning behind the tenet itself.
